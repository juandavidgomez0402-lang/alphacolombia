# Alphacolombia - Landing Page Cyberpunk

🚀 **Landing page moderna con estética cyberpunk para Alphacolombia**

## 📋 Descripción

Proyecto web responsive con diseño cyberpunk que presenta las aplicaciones Alpha de Alphacolombia. Incluye contenedores interactivos para descarga de apps, sistema de soporte y sección de preguntas frecuentes.

## ✨ Características

- 🎨 **Diseño Cyberpunk**: Estética visual moderna con efectos neon y glassmorphism
- 📱 **Responsive Design**: Optimizado para dispositivos móviles y desktop
- ⚡ **Interactivo**: Contenedores clickeables con redirección directa
- 🌟 **Animaciones**: Efectos glow, partículas flotantes y transiciones suaves
- 🔗 **Integración**: Enlaces directos a descargas y soporte

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica moderna
- **CSS3**: Flexbox, Grid, Animaciones y Media Queries
- **JavaScript**: Interactividad y funcionalidad FAQ
- **Google Fonts**: Orbitron y Rajdhani para tipografía cyberpunk

## 🚀 Instalación y Uso

### Local Development
1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/alphacolombia.git
   cd alphacolombia
   ```

2. Inicia servidor local:
   ```bash
   python -m http.server 8000
   # o usa Live Server en VS Code
   ```

3. Abre `http://localhost:8000` en tu navegador

### Deploy en Vercel
1. **Prepara el repositorio**:
   - Asegúrate que todos los archivos estén en la raíz
   - Verifica que el `index.html` esté en el directorio principal

2. **Sube a GitHub**:
   ```bash
   git add .
   git commit -m "Deploy Alphacolombia Landing Page"
   git push origin main
   ```

3. **Configura Vercel**:
   - Ve a [vercel.com](https://vercel.com)
   - Importa tu repositorio de GitHub
   - Vercel detectará automáticamente que es un sitio estático
   - Haz clic en "Deploy"
